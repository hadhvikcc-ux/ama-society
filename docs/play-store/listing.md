## 3. Visual Assets Checklist

All required store listing assets are generated and located in `apps/mobile/assets/`:

1. **App Icon**: `apps/mobile/assets/icon.png`
   - Specification: 512 x 512 px, 32-bit PNG, max 1024 KB.
2. **Feature Graphic**: `apps/mobile/assets/feature-graphic.png`
   - Specification: 1024 x 500 px, 24-bit PNG, no alpha channel.
3. **Adaptive Icon**: `apps/mobile/assets/adaptive-icon.png`
   - Specification: 432 x 432 px with transparent margins for Android 13+ thematic icons.
4. **Splash Screen**: `apps/mobile/assets/splash.png`
   - Specification: 1284 x 2778 px for crisp mobile boot on modern edge-to-edge displays.
